AI-Assisted Coding

Run /init inside an AI coding tool to initialize its understanding of the current project. It usually analyzes the repository and creates or updates a project instruction file that gives the tool persistent context.

Start in the project root and run /init.

Coding-agent instructions can apply globally, to one project, or to one developer's personal workflow.

  • Claude Code: global ~/.claude/CLAUDE.md, project ./CLAUDE.md, personal/local ./CLAUDE.local.md.
  • Cursor: global User Rules in Cursor settings, shared project rules in .cursor/rules/*.mdc, or project instructions in AGENTS.md.
  • OpenCode: global ~/.config/opencode/AGENTS.md and project ./AGENTS.md; personal preferences can be kept in global configuration unless the tool's project setup specifically needs them.

  • Local: available only in the current project for the current user.
  • User: available across all projects for the current user.
  • Project: defined in .mcp.json, shared through version control, and available to everyone working on the project.
