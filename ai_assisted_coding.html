AI-Assisted Coding

Run /init inside an AI coding tool to initialize its understanding of the current project. It usually analyzes the repository and creates or updates a project instruction file that gives the tool persistent context.

  • The generated instructions may include the project purpose, structure, frameworks, coding conventions, build commands, and test commands.
  • Examples of tool-specific instruction files include CLAUDE.md, AGENTS.md, and Cursor project rules.
  • Review the generated instructions because incorrect assumptions can be reused in future sessions.
  • Commit useful project instructions when they help every developer or agent work consistently.
  • Update the instructions when major architecture, tooling, or workflow conventions change.

Example: start in the project root, run /init, then verify that commands such as setup, build, lint, and tests are described correctly.
